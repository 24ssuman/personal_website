# Suman Saha Personal Website

Static academic website for Suman Saha, Ph.D. Candidate in Chemistry at UC San Diego.

## Website

https://24ssuman.github.io/personal_website/

## Files

- `index.html` is the single scrolling site, with anchor-linked Home, Research, Publications, Projects, and Beyond the Lab sections.
- `style.css` contains the visual system (Source Serif 4 headings, Inter body text, deep-teal accent), layout, and responsive behavior.
- `assets/` contains local website visuals.
