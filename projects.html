Molecular Dynamics Tutorial for Beginners

A beginner-friendly, concept-first course on molecular dynamics and enhanced sampling. Follow the physics and Python code behind each step, then explore live, slider-driven simulations directly in your browser.

Open Interactive Course GitHub Repo More Details
  • Course Modules: Progresses from MD fundamentals and forces through sampling, umbrella sampling, metadynamics, and Lennard-Jones fluids, with supplements on collective variables and WHAM.
  • Python Walkthroughs: Explanations include expandable, copyable Python examples that show the code behind each step.
  • Live Browser Demos: Adjust sliders and controls to explore simulations and see plots respond in real time.

Epoch — Offline Sky Simulator

Explore the sky from any location on Earth across 20,000 years, from 15,000 BCE to 5,000 CE. Epoch pairs a React and Three.js interface with a Python scientific service, and runs offline after its data is installed.

GitHub Repo More Details
  • Explore the sky: Choose a location and date, then search stars, planets, and comets.
  • Local and offline: The app downloads its data during setup and runs without an internet connection afterward.
  • Scientific limits: Planetary positions before about 13,200 BCE use a reduced-model extrapolation; ancient local times are uncertain.

LitScope — Research Feed & Reading Library

Keep up with recent journal articles and preprints in one place. LitScope brings research feeds into a searchable library with saved reading queues, journal management, and one-click citation copying. Runs locally with Node.js.

GitHub Repo More Details
  • Follow the literature: Track journals and preprints through RSS and supported APIs, including arXiv and ChemRxiv, and add your own feeds.
  • Organize your reading: Save articles, search titles, authors, abstracts, and DOIs, and filter by journal, author, or date.
  • Make it yours: Copy citations, export article metadata to CSV, and choose from seven palettes with light and dark modes.
